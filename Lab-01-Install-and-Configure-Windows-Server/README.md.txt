Lab 01 - Install and Configure Windows Server

Objective

Install and configure Windows Server in VMware Workstation using a Windows Server ISO image.

--> Lab Environment

1. Hypervisor: VMware Workstation
2. Operating System: Windows Server 2022
3. Installation Media: Windows Server ISO
4. Virtual Machine: Windows Server VM

--> Lab Tasks

1. Download the Windows Server ISO file.
2. Create a new virtual machine in VMware Workstation.
3. Select the Windows Server ISO as the installation media.
4. Select the location for storing the virtual machine files.
5. Configure the language and regional settings.
6. Start the Windows Server operating system setup.
7. Install Windows Server files.
8. Configure the built-in Administrator account.
9. Complete the Windows Server installation and verify the configuration.
